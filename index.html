자주 묻는 질문

궁금한 점을 모았어요

삼성헬스 외 다른 워치도 지원하나요? +
현재 베타 버전은 삼성헬스 운동 상세 화면 스크린샷 인식에 최적화되어 있습니다. 다른 워치 사용자는 수동 입력 폼으로 데이터를 입력하실 수 있습니다. 추후 정식 출시 시 삼성헬스 SDK 연동을 통해 자동 동기화를 지원할 예정입니다.
iOS 버전은 언제 나오나요? +
안드로이드 정식 출시 후 iOS 버전을 준비할 예정입니다. 출시 일정은 베타 테스트 결과에 따라 조정될 수 있어요.
내 데이터는 어디에 저장되나요? +
수영 기록은 기본적으로 사용자의 기기 내부에 저장됩니다. 회원 정보(이메일, 이름, 멤버십 등급)는 Supabase 보안 서버에 암호화되어 저장됩니다. 자세한 내용은 개인정보처리방침을 확인해주세요.
구독을 취소하면 데이터가 삭제되나요? +
아니요. 구독을 취소해도 기존에 입력한 수영 기록은 그대로 유지됩니다. 다만 PRO/PLUS 전용 기능에는 더 이상 접근할 수 없게 됩니다.
OCR 인식이 잘못 되었어요. 어떻게 하나요? +
인식 결과가 의심스러우면 자동으로 검토 화면이 뜹니다. 거기서 직접 수정하시거나, 아예 수동 입력 폼을 사용하시면 정확한 분석이 가능합니다. 반복적으로 같은 영법이 인식 안 된다면 문의로 스크린샷을 보내주세요.
환불 정책은 어떻게 되나요? +
구독 결제 후 환불은 Google Play의 환불 정책을 따릅니다. 일반적으로 결제 후 48시간 이내 신청 시 자동 환불되며, 그 이후는 Google에 직접 환불 요청을 하셔야 합니다.
